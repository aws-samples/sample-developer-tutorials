# Healthlake Getting Started

Amazon HealthLake Tutorial

## Prerequisites

- AWS CLI configured with credentials
- Python 3.8+ with boto3 installed
- Sufficient IAM permissions for healthlake

## Run

**Python:**
```bash
python3 healthlake-gs.py
```

**CLI:**
```bash
bash healthlake-gs.sh
```
