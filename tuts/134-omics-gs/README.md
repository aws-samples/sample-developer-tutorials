# Amazon Omics — Getting Started Tutorial

Demonstrates the core Amazon Omics workflow: creating resources, verifying them, and cleaning up.

## Prerequisites

- AWS CLI v2 installed and configured
- Python 3.9+ with boto3
- IAM permissions for omics:Create*, omics:Delete*, omics:Get*, omics:List*
- (Optional) TUTORIAL_ROLE_ARN environment variable if the service requires a role

## Run

**Python:**
```bash
python3 omics-gs.py
```

**CLI:**
```bash
bash omics-gs.sh
```

Both scripts create resources, verify them, and clean up automatically.
