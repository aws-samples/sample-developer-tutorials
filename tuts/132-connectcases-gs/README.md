# Amazon Connect Cases — Getting Started Tutorial

Demonstrates the core Amazon Connect Cases workflow: creating resources, verifying them, and cleaning up.

## Prerequisites

- AWS CLI v2 installed and configured
- Python 3.9+ with boto3
- IAM permissions for connectcases:Create*, connectcases:Delete*, connectcases:Get*, connectcases:List*
- (Optional) TUTORIAL_ROLE_ARN environment variable if the service requires a role

## Run

**Python:**
```bash
python3 connectcases-gs.py
```

**CLI:**
```bash
bash connectcases-gs.sh
```

Both scripts create resources, verify them, and clean up automatically.
