# AWS Well-Architected Tool — Getting Started Tutorial

Demonstrates the core AWS Well-Architected Tool workflow: creating resources, verifying them, and cleaning up.

## Prerequisites

- AWS CLI v2 installed and configured
- Python 3.9+ with boto3
- IAM permissions for wellarchitected:Create*, wellarchitected:Delete*, wellarchitected:Get*, wellarchitected:List*
- (Optional) TUTORIAL_ROLE_ARN environment variable if the service requires a role

## Run

**Python:**
```bash
python3 wellarchitected-gs.py
```

**CLI:**
```bash
bash wellarchitected-gs.sh
```

Both scripts create resources, verify them, and clean up automatically.
