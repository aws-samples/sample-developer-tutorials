# Autoscaling Plans Getting Started

Tutorial: Create and Manage an AWS Auto Scaling Plan

## Prerequisites

- AWS CLI configured with credentials
- Python 3.8+ with boto3 installed
- Sufficient IAM permissions for autoscaling-plans

## Run

**Python:**
```bash
python3 autoscaling-plans-gs.py
```

**CLI:**
```bash
bash autoscaling-plans-gs.sh
```
