# Marketplace Deployment Getting Started

Tutorial for Getting Started with Marketplace Deployment

## Prerequisites

- AWS CLI configured with credentials
- Python 3.8+ with boto3 installed
- Sufficient IAM permissions for marketplace-deployment

## Run

**Python:**
```bash
python3 marketplace-deployment-gs.py
```

**CLI:**
```bash
bash marketplace-deployment-gs.sh
```
