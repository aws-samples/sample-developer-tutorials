# Cloud9 Getting Started

Cloud9 Environment Simulation Tutorial

## Prerequisites

- AWS CLI configured with credentials
- Python 3.8+ with boto3 installed
- Sufficient IAM permissions for cloud9

## Run

**Python:**
```bash
python3 cloud9-gs.py
```

**CLI:**
```bash
bash cloud9-gs.sh
```
