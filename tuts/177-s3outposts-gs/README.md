# S3Outposts Getting Started

Tutorial for Getting Started with S3Outposts

## Prerequisites

- AWS CLI configured with credentials
- Python 3.8+ with boto3 installed
- Sufficient IAM permissions for s3outposts

## Run

**Python:**
```bash
python3 s3outposts-gs.py
```

**CLI:**
```bash
bash s3outposts-gs.sh
```
