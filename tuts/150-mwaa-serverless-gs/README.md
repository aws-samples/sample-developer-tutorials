# Mwaa Serverless Getting Started

Aws Mwaa Serverless Tutorial

## Prerequisites

- AWS CLI configured with credentials
- Python 3.8+ with boto3 installed
- Sufficient IAM permissions for mwaa-serverless

## Run

**Python:**
```bash
python3 mwaa-serverless-gs.py
```

**CLI:**
```bash
bash mwaa-serverless-gs.sh
```

This script creates resources, demonstrates their use, and cleans up automatically.
