# Pca Connector Scep Getting Started

Tutorial for interacting with pca-connector-scep using boto3

## Prerequisites

- AWS CLI configured with credentials
- Python 3.8+ with boto3 installed
- Sufficient IAM permissions for pca-connector-scep

## Run

**Python:**
```bash
python3 pca-connector-scep-gs.py
```

**CLI:**
```bash
bash pca-connector-scep-gs.sh
```
