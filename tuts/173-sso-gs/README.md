# Sso Getting Started

Tutorial for Getting Started with Sso

## Prerequisites

- AWS CLI configured with credentials
- Python 3.8+ with boto3 installed
- Sufficient IAM permissions for sso

## Run

**Python:**
```bash
python3 sso-gs.py
```

**CLI:**
```bash
bash sso-gs.sh
```
