# Mediastore Data Getting Started

Tutorial for Getting Started with Mediastore Data

- AWS CLI configured with credentials
- Python 3.8+ with boto3 installed
- Sufficient IAM permissions for mediastore-data

## Run

**Python:**
```bash
python3 mediastore-data-gs.py
```

```bash
bash mediastore-data-gs.sh
```
