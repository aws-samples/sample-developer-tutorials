# Controlcatalog Getting Started

Tutorial for Getting Started with Controlcatalog

## Prerequisites

- AWS CLI configured with credentials
- Python 3.8+ with boto3 installed
- Sufficient IAM permissions for controlcatalog

## Run

**Python:**
```bash
python3 controlcatalog-gs.py
```

**CLI:**
```bash
bash controlcatalog-gs.sh
```
