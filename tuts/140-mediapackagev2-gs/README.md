# AWS Elemental MediaPackage v2 — Getting Started Tutorial

Demonstrates the core AWS Elemental MediaPackage v2 workflow: creating resources, verifying them, and cleaning up.

## Prerequisites

- AWS CLI v2 installed and configured
- Python 3.9+ with boto3
- IAM permissions for mediapackagev2:Create*, mediapackagev2:Delete*, mediapackagev2:Get*, mediapackagev2:List*
- (Optional) TUTORIAL_ROLE_ARN environment variable if the service requires a role

## Run

**Python:**
```bash
python3 mediapackagev2-gs.py
```

**CLI:**
```bash
bash mediapackagev2-gs.sh
```

Both scripts create resources, verify them, and clean up automatically.
