# Sagemaker A2I Runtime Getting Started

Tutorial for Getting Started with Sagemaker A2I Runtime

## Prerequisites

- AWS CLI configured with credentials
- Python 3.8+ with boto3 installed
- Sufficient IAM permissions for sagemaker-a2i-runtime

## Run

**Python:**
```bash
python3 sagemaker-a2i-runtime-gs.py
```

**CLI:**
```bash
bash sagemaker-a2i-runtime-gs.sh
```
