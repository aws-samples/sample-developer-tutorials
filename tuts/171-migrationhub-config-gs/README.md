# Migrationhub Config Getting Started

Tutorial for Getting Started with Migrationhub Config

## Prerequisites

- AWS CLI configured with credentials
- Python 3.8+ with boto3 installed
- Sufficient IAM permissions for migrationhub-config

## Run

**Python:**
```bash
python3 migrationhub-config-gs.py
```

**CLI:**
```bash
bash migrationhub-config-gs.sh
```
