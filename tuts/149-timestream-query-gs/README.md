# Timestream Query Getting Started

Tutorial: Creating and Managing a Scheduled Query in Amazon Timestream

## Prerequisites

- AWS CLI configured with credentials
- Python 3.8+ with boto3 installed
- Sufficient IAM permissions for timestream-query

## Run

**Python:**
```bash
python3 timestream-query-gs.py
```

**CLI:**
```bash
bash timestream-query-gs.sh
```
