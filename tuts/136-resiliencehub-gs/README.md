# AWS Resilience Hub — Getting Started Tutorial

Demonstrates the core AWS Resilience Hub workflow: creating resources, verifying them, and cleaning up.

## Prerequisites

- AWS CLI v2 installed and configured
- Python 3.9+ with boto3
- IAM permissions for resiliencehub:Create*, resiliencehub:Delete*, resiliencehub:Get*, resiliencehub:List*
- (Optional) TUTORIAL_ROLE_ARN environment variable if the service requires a role

## Run

**Python:**
```bash
python3 resiliencehub-gs.py
```

**CLI:**
```bash
bash resiliencehub-gs.sh
```

Both scripts create resources, verify them, and clean up automatically.
