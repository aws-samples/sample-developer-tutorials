# Amazon Security Lake — Getting Started Tutorial

Demonstrates the core Amazon Security Lake workflow: creating resources, verifying them, and cleaning up.

## Prerequisites

- AWS CLI v2 installed and configured
- Python 3.9+ with boto3
- IAM permissions for securitylake:Create*, securitylake:Delete*, securitylake:Get*, securitylake:List*
- (Optional) TUTORIAL_ROLE_ARN environment variable if the service requires a role

## Run

**Python:**
```bash
python3 securitylake-gs.py
```

**CLI:**
```bash
bash securitylake-gs.sh
```

Both scripts create resources, verify them, and clean up automatically.
