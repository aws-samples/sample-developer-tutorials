# Cloudfront Keyvaluestore Getting Started

Tutorial for Getting Started with Cloudfront Keyvaluestore

## Prerequisites

- AWS CLI configured with credentials
- Python 3.8+ with boto3 installed
- Sufficient IAM permissions for cloudfront-keyvaluestore

## Run

**Python:**
```bash
python3 cloudfront-keyvaluestore-gs.py
```

**CLI:**
```bash
bash cloudfront-keyvaluestore-gs.sh
```
