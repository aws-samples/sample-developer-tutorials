# Ebs Getting Started

Tutorial for Getting Started with Ebs

## Prerequisites

- AWS CLI configured with credentials
- Python 3.8+ with boto3 installed
- Sufficient IAM permissions for ebs

## Run

**Python:**
```bash
python3 ebs-gs.py
```

**CLI:**
```bash
bash ebs-gs.sh
```
