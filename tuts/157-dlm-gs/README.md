# Dlm Getting Started

Tutorial: Create, Retrieve, and Delete an Amazon Data Lifecycle Manager (DLM) Policy

## Prerequisites

- AWS CLI configured with credentials
- Python 3.8+ with boto3 installed
- Sufficient IAM permissions for dlm

## Run

**Python:**
```bash
python3 dlm-gs.py
```

**CLI:**
```bash
bash dlm-gs.sh
```

## Resources Created

This script creates resources, demonstrates their use, and cleans up automatically.
