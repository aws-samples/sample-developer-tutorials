# Launch Wizard Getting Started

Launch Wizard Tutorial

## Prerequisites

- AWS CLI configured with credentials
- Python 3.8+ with boto3 installed
- Sufficient IAM permissions for launch-wizard

## Run

**Python:**
```bash
python3 launch-wizard-gs.py
```

**CLI:**
```bash
bash launch-wizard-gs.sh
```
