# Serverlessrepo Getting Started

Serverless Application Repository Tutorial

## Prerequisites

- AWS CLI configured with credentials
- Python 3.8+ with boto3 installed
- Sufficient IAM permissions for serverlessrepo

## Run

**Python:**
```bash
python3 serverlessrepo-gs.py
```

**CLI:**
```bash
bash serverlessrepo-gs.sh
```

## Resources Created

This script creates resources, demonstrates their use, and cleans up automatically.
