# Pricing Getting Started

Tutorial for Getting Started with Pricing

## Prerequisites

- AWS CLI configured with credentials
- Python 3.8+ with boto3 installed
- Sufficient IAM permissions for pricing

## Run

**Python:**
```bash
python3 pricing-gs.py
```

**CLI:**
```bash
bash pricing-gs.sh
```
