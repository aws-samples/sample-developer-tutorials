# Uxc Getting Started

Tutorial for Getting Started with Uxc

## Prerequisites

- AWS CLI configured with credentials
- Python 3.8+ with boto3 installed
- Sufficient IAM permissions for uxc

## Run

**Python:**
```bash
python3 uxc-gs.py
```

**CLI:**
```bash
bash uxc-gs.sh
```
