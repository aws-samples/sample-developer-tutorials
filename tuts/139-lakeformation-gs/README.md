# AWS Lake Formation — Getting Started Tutorial

Demonstrates the core AWS Lake Formation workflow: creating resources, verifying them, and cleaning up.

## Prerequisites

- AWS CLI v2 installed and configured
- Python 3.9+ with boto3
- IAM permissions for lakeformation:Create*, lakeformation:Delete*, lakeformation:Get*, lakeformation:List*
- (Optional) TUTORIAL_ROLE_ARN environment variable if the service requires a role

## Run

**Python:**
```bash
python3 lakeformation-gs.py
```

**CLI:**
```bash
bash lakeformation-gs.sh
```

Both scripts create resources, verify them, and clean up automatically.
