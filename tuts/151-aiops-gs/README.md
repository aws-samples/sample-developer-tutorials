# Aiops Getting Started

Tutorial: Create and Manage an Investigation Group with AWS AIOps

## Prerequisites

- AWS CLI configured with credentials
- Python 3.8+ with boto3 installed
- Sufficient IAM permissions for aiops

## Run

**Python:**
```bash
python3 aiops-gs.py
```

**CLI:**
```bash
bash aiops-gs.sh
```
