# AWS Billing Conductor — Getting Started Tutorial

Demonstrates the core AWS Billing Conductor workflow: creating resources, verifying them, and cleaning up.

## Prerequisites

- AWS CLI v2 installed and configured
- Python 3.9+ with boto3
- IAM permissions for billingconductor:Create*, billingconductor:Delete*, billingconductor:Get*, billingconductor:List*
- (Optional) TUTORIAL_ROLE_ARN environment variable if the service requires a role

## Run

**Python:**
```bash
python3 billingconductor-gs.py
```

**CLI:**
```bash
bash billingconductor-gs.sh
```

Both scripts create resources, verify them, and clean up automatically.
