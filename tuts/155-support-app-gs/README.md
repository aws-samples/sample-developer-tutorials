# Support App Getting Started

Tutorial: Managing Slack Channel Configurations with AWS Support App

## Prerequisites

- AWS CLI configured with credentials
- Python 3.8+ with boto3 installed
- Sufficient IAM permissions for support-app

## Run

**Python:**
```bash
python3 support-app-gs.py
```

**CLI:**
```bash
bash support-app-gs.sh
```
