# AWS IoT Events — Getting Started Tutorial

Demonstrates the core AWS IoT Events workflow: creating resources, verifying them, and cleaning up.

## Prerequisites

- AWS CLI v2 installed and configured
- Python 3.9+ with boto3
- IAM permissions for iotevents:Create*, iotevents:Delete*, iotevents:Get*, iotevents:List*
- (Optional) TUTORIAL_ROLE_ARN environment variable if the service requires a role

## Run

**Python:**
```bash
python3 iotevents-gs.py
```

**CLI:**
```bash
bash iotevents-gs.sh
```

Both scripts create resources, verify them, and clean up automatically.
